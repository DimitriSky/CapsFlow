# App icon

`AppIcon-master.png` is the original artwork generated with the built-in image generation tool. The macOS app icon sizes are in `Assets.xcassets/AppIcon.appiconset` and were resized with `sips`, preserving transparency.

## Generation prompt

```text
Use case: logo-brand
Asset type: production macOS app icon for CapsFlow, a utility that switches keyboard languages with Caps Lock.
Primary request: Design one polished, distinctive native macOS app icon, square 1024x1024 canvas. A single softly sculpted keycap with a bold Caps Lock glyph (an upward arrow with a detached horizontal bar beneath it) is the main recognizable form. Integrate a simple pair of flowing exchange arrows around the lower part of the keycap to suggest switching input languages. Restrained native macOS utility aesthetic, refined dimensional materials, subtle highlights and depth, strong clear silhouette and high contrast. Front view, centered composition; artwork contained inside one rounded-square app tile with consistent macOS-style safe margins, transparent space outside the tile. The icon must read at 32px. Deliver the actual icon artwork only.
Constraints: no app name, no letters, no words, no watermark, no extra icons, no device mockup, no desktop scene, no image border, no busy texture. Preserve generous clarity in the Caps Lock glyph; avoid excessive tiny details.
```
